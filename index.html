03About

I live in Charlotte, North Carolina. I've worked in IT for fourteen years, most of it building data platforms for aviation, banking, telecom, hospitality and retail.

I like building things, and I find it hard to leave a working thing alone. A pipeline that runs should run without anyone watching it. A query that works can usually cost less. I go back over my own work more often than anyone asks me to.

Cloakroom started as a home project. I was setting up an AI model to run on my own machine, because I wanted my files to stay private. I wanted the same privacy when I used Claude Code, and nothing did it the way I needed. So I built it, and made it open source.

Most days I work in Snowflake, dbt, Airflow, Python and AWS.
